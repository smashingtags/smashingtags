## What I Build

**[HomelabARR](https://homelabarr.com)** — NAS management and Docker container deployment for homelabs. CE is free and open source with 137 app templates. PE adds SnapRAID + MergerFS for mixed drive sizes.

**[AI Agent Templates](https://agents.imogenlabs.ai)** — 9 production-tested OpenClaw agent configs for Docker monitoring, security audits, crypto/stock alerts, content automation, and project management. All powered by free public APIs.

**[Operator Kit](https://www.npmjs.com/package/@imogenlabs/operator-kit)** — OpenClaw plugin that scaffolds a complete AI operator: identity, memory, instincts, cron jobs, and multi-agent dispatch.

**[MediaClaw](https://media.imogenlabs.ai)** — Managed Plex + arr stack hosting on dedicated hardware.

**NeuroHelper** — iOS wellness app for ADHD and autism. Breathing exercises, AI chat, medication tracking, brain games.

**[Mission Control](https://github.com/smashingtags/mission-control)** — Operations dashboard for AI agents. Task board, cron monitoring, memory browser.

## Infrastructure

Everything runs on self-hosted infrastructure: Proxmox cluster, Docker hosts, Traefik reverse proxy, Cloudflare, and an AI operator ([Imogen](https://imogenlabs.ai)) that handles ops 24/7.

```
Mac Mini M4         → Build server, OpenClaw, Claude Code
Docker Host (195)   → 34+ production containers, Traefik, all websites
Proxmox (49)        → VMs and LXCs
Hetzner Bare Metal  → Managed hosting (OpenClaw + MediaClaw)
```
